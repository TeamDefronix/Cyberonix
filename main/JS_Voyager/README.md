# JS-Voyager

JS-Voyager is a tool designed to crawl websites, download JavaScript files, extract endpoints, visualize dependencies, and generate reports.

## Features
- Website crawling
- JavaScript file downloading
- Endpoint extraction
- Graph visualization (using networkx + pyvis)
- Reporting module

## Usage
```bash
pip install -r requirements.txt
python main.py --url https://target.com
```
